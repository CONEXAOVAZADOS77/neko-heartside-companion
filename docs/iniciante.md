# Neko IA — trilha iniciante

Use este modo se você está começando com IA.

1. Abra a conta e escolha **Iniciante**.
2. No painel, use só: Gerar Foto, Gerar Vídeo, Criar Influencer, Galeria e Créditos.
3. Se precisar de TikTok Shop, Motion ou +18, peça para quem usa o modo avançado trocar o perfil no menu lateral.
